# 🧱 ValeLadder

**From ping to VPN** — a structured learning path for Swift system programming on macOS.

This repository contains **only final, polished versions** of utilities.  
For drafts and experiments, see [ValeNetUtils](https://github.com/vale-ponick/ValeNetUtils).

## 📁 Structure

| Step | Projects |
|------|----------|
| `Step1_Network` | PingChecker, DiskFree, ProcessList, Uptime |
| `Step2_System` | DNSChanger, ProxyToggle, LaunchAtLogin |
| `Step3_Security` | KeychainStorage, ConfigParser |
| `Step4_Processes` | CommandRunner, WireGuardCLIWrapper |
| `Step5_Final` | MyVPNClient |

## 🎯 Goal

Learn Swift system programming by building a custom VPN client from scratch.
